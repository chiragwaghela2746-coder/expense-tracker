💰 Expense Tracker
A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript.

🚀 Features

•Add new expenses

•Delete expenses

•Automatic total calculation

•Data persistence using Local Storage

•Dark mode UI

•Responsive design

•Real-time updates


🛠️ Technologies Used

•HTML5

•CSS3

•JavaScript (ES6)

•Local Storage API
